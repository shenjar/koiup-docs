# 如何使用 API 服务

## 加入服务

欢迎使用 KoiUP 官方服务！

我们的 API 接入网站为 [https://koiup.com](https://koiup.com)

我们已全面调整为**按量计费**模式，支持 Claude、Codex、Gemini 等多个渠道。

## 🚀 加入步骤

1. 前往 [KoiUP 控制台](https://koiup.com) 注册账号或登录。
2. 在控制台左侧找到**充值**菜单。
3. 选择合适的金额完成充值。
4. 进入 **API 密钥**菜单，点击创建密钥并选择分组。
5. 点击**查看接入地址**，即可开始使用。
