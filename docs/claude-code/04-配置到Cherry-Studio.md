# 4. 配置到 Cherry Studio 中

## 适用范围

用于将 Cherry Studio 接入兼容 Anthropic API 的第三方中转站、代理或网关。

开始前请确认你已获取：
- **API 密钥**：进入 [KoiUP 控制台](https://koiup.com/keys)，点击菜单 **API密钥**
- **API 端点**：进入 [KoiUP 控制台](https://koiup.com/keys)，点击菜单 **API密钥**

---

## 步骤 1：打开 Cherry Studio 设置

1. 打开设置
2. 在左侧的模型平台列表点击**添加**

## 步骤 2：添加提供商

1. 随便输入一个名称
2. 提供商类型选择 **Anthropic**
3. 点击**确定**

## 步骤 3：输入 API 密钥和 API 地址

1. 输入 API 密钥和 API 地址（从 [KoiUP 控制台](https://koiup.com/keys) 获取）
2. 点击**获取模型列表**
3. 如果 API 可用，会出现模型列表，点击**添加所有**，再点击**确定**
4. 然后关闭页面，返回首页

## 步骤 4：验证是否成功

1. 点击模型切换位置可切换模型
2. 选择刚刚添加的模型
3. 发送 `hi` 测试是否可用
