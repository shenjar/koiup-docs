# 2. 配置到 Visual Studio 的 Codex 插件中

## 适用范围

用于将 VSCode、Cursor 等 IDE 中的 Codex 插件接入兼容 OpenAI API 的第三方中转站、代理或网关。

开始前请确认你已获取：
- **API 密钥**：进入 [KoiUP 控制台](https://koiup.com/keys)，点击菜单 **API密钥**
- **API 端点**：进入 [KoiUP 控制台](https://koiup.com/keys)，点击菜单 **API密钥**

---

## 配置方式

在 VSCode 插件设置中填入：
- **Base URL / API Endpoint**：你的 API 端点
- **API Key**：你的 API 密钥

具体配置路径因插件版本而异，请参考插件文档中的 "Custom API Endpoint" 或 "Base URL" 配置项。
