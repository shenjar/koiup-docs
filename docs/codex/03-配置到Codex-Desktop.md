# 3. 配置到 Codex Desktop 中

## 适用范围

用于将 Codex Desktop 接入兼容 OpenAI API 的第三方中转站、代理或网关。

开始前请确认你已获取：
- **API 密钥**：进入 [KoiUP 控制台](https://koiup.com/keys)，点击菜单 **API密钥**
- **API 端点**：进入 [KoiUP 控制台](https://koiup.com/keys)，点击菜单 **API密钥**

---

## 配置步骤

1. 打开 Codex Desktop 设置页面。
2. 找到 **API Configuration** 或 **自定义端点** 选项。
3. 填入 **Base URL**：你的 API 端点
4. 填入 **API Key**：你的 API 密钥
5. 保存配置后重启应用。
6. 发送一条测试消息，验证是否配置成功。
