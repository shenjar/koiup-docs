# 常见报错

## 401 Unauthorized

**原因**：API 密钥不正确或已过期。

**解决方案**：
1. 进入 [KoiUP 控制台](https://koiup.com/keys) 检查 API 密钥是否正确
2. 确认密钥没有被删除或禁用
3. 重新复制密钥并更新配置

---

## 402 Payment Required / 余额不足

**原因**：账户余额不足，无法继续调用 API。

**解决方案**：
1. 登录 [KoiUP 控制台](https://koiup.com) 充值
2. 充值后重新发起请求

---

## 403 Forbidden

**原因**：当前密钥无权限访问该模型或分组。

**解决方案**：
1. 检查密钥所属分组是否有权限访问目标模型
2. 更换密钥或联系客服 [support@koiup.com](mailto:support@koiup.com)

---

## 429 Too Many Requests

**原因**：请求频率超出限制。

**解决方案**：
1. 降低请求频率
2. 实现请求重试和退避策略

---

## 500 Internal Server Error

**原因**：服务器内部错误。

**解决方案**：
1. 稍后重试
2. 如持续出现，请联系客服 [support@koiup.com](mailto:support@koiup.com)

---

## Connection refused / 无法连接

**原因**：API 端点地址配置错误。

**解决方案**：
1. 进入 [KoiUP 控制台](https://koiup.com/keys) 重新获取正确的 API 端点地址
2. 检查配置文件中的 `ANTHROPIC_BASE_URL` 或 `OPENAI_BASE_URL` 是否正确

---

## 如有其他问题

请联系官方客服：[support@koiup.com](mailto:support@koiup.com)
