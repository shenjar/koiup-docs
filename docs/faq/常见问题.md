# 常见问题

## Q: 如何获取 API 密钥？

进入 [KoiUP 控制台](https://koiup.com/keys)，在 **API密钥** 菜单中创建密钥并选择分组，然后查看接入地址。

## Q: 支持哪些模型？

平台支持 Claude、Codex、Gemini 等多个渠道的模型，具体模型列表请在控制台查看。

## Q: 充值后余额多久到账？

充值完成后余额实时到账，1 CNY = 1 $。

## Q: API 端点地址是什么？

进入 [KoiUP 控制台](https://koiup.com/keys)，在 **API密钥** 页面点击**查看接入地址**获取。

## Q: 如何查看使用记录和消费明细？

登录 [KoiUP 控制台](https://koiup.com)，在对应菜单中可查看调用记录和账单明细。

## Q: 余额不足会怎样？

余额不足时，API 请求将被拒绝或执行失败，系统会提示余额不足，请及时充值。
